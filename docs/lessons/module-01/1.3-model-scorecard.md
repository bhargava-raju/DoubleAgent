**Syllabus:** Module 1, compare models on the same business task: quality, latency, privacy, and cost.
**You implement:** everything in `src/doubleagent/scorecard.py`, and the `compare` CLI command.
**Done when:** `uv run pytest tests/module01/test_scorecard.py` is green, plus ruff and pyright, and

## Concepts

### What you're trading off

| Dimension | How to measure it here | What drives it |
|-----------|------------------------|----------------|
| **Quality** | `keyword_quality`: fraction of expected facts in the answer | model capability, prompt, provided context |
| **Latency** | wall-clock ms around the call (`time.perf_counter`) | model size, output length, thinking |
| **Cost** | tokens × price per million (`usage` × `PRICES`) | input size (history, documents), output length, model tier |
| **Privacy** | not measured in code: where data is processed, retention, contract terms | provider, deployment (API, Bedrock, Vertex), data-handling settings |

One run is an anecdote. Real comparisons repeat each task and use many tasks (Module 6). Keyword matching is crude
on purpose: notice where it's wrong, because that's the motivation for LLM-as-judge evals later.

### Python you'll use

- **`@dataclass(frozen=True, slots=True)`** ≈ a C# `record`: generated constructor, equality and `repr`, immutable.
  Use dataclasses for internal values; Pydantic where data crosses a boundary and must be validated.
- **Format specs**: `f"{0.6667:.0%}"` → `67%`, `f"{812.4:.0f}"` → `812`, `f"{0.0015:.6f}"` → `0.001500`.
- **`sum` over booleans**: `True` counts as 1, so `sum(k in text for k in keywords)` counts matches.
- **Nested `async def` + `asyncio.gather`** ≈ `await Task.WhenAll(models.Select(RunOneAsync))`. `gather` returns
  results in the order you passed them, even though they run concurrently.
- **`csv.DictWriter`** and **`with path.open(...) as f:`** ≈ `using var writer = new StreamWriter(...)`.
  Always pass `newline=""` for CSV and an explicit `encoding`.

1. Implement `estimate_cost_usd` and `keyword_quality`. Run the tests with `-k "cost or quality"`.
2. Implement `compare_models` sequentially first. Then switch to `asyncio.gather` and compare the total time.

4. Wire up `doubleagent compare` in `cli.py`. Use this task, or write your own:
   - task: *"A buyer wants to order hydraulic pumps. Supplier records: <paste SUP-001 and SUP-005 JSON>.

   or save the paragraph under `notes/`.)
