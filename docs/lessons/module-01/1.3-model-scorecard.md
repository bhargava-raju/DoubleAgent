# 1.3 Model comparison scorecard

**Syllabus:** Module 1, compare models on the same business task: quality, latency, privacy, and cost.
**You implement:** everything in `src/doubleagent/scorecard.py`, and the `compare` CLI command.
**Done when:** `uv run pytest tests/module01/test_scorecard.py` is green, plus ruff and pyright, and
`uv run doubleagent compare` prints a table and writes `reports/scorecard.csv`.

> The syllabus compares GPT, Claude and Gemini. We compare Claude's tiers (Haiku 4.5, Sonnet 5.5, Opus 5.5)
> through the Anthropic SDK. The method is the same: one task, fixed checks, measured cost and latency.
> In 1.4, LangChain makes adding another provider a one-line change if you want to extend the comparison.

## Concepts

### What you're trading off

| Dimension | How to measure it here | What drives it |
|-----------|------------------------|----------------|
| **Quality** | `keyword_quality`: fraction of expected facts in the answer | model capability, prompt, provided context |
| **Latency** | wall-clock ms around the call (`time.perf_counter`) | model size, output length, thinking |
| **Cost** | tokens × price per million (`usage` × `PRICES`) | input size (history, documents), output length, model tier |
| **Privacy** | not measured in code: where data is processed, retention, contract terms | provider, deployment (API, Bedrock, Vertex), data-handling settings |

One run is an anecdote. Real comparisons repeat each task and use many tasks (Module 6). Keyword matching is crude
on purpose: notice where it's wrong, because that's the motivation for LLM-as-judge evals later.

### Python you'll use

- **`@dataclass(frozen=True, slots=True)`** ≈ a C# `record`: generated constructor, equality and `repr`, immutable.
  Use dataclasses for internal values; Pydantic where data crosses a boundary and must be validated.
- **Format specs**: `f"{0.6667:.0%}"` → `67%`, `f"{812.4:.0f}"` → `812`, `f"{0.0015:.6f}"` → `0.001500`.
- **`sum` over booleans**: `True` counts as 1, so `sum(k in text for k in keywords)` counts matches.
- **Nested `async def` + `asyncio.gather`** ≈ `await Task.WhenAll(models.Select(RunOneAsync))`. `gather` returns
  results in the order you passed them, even though they run concurrently.
- **`csv.DictWriter`** and **`with path.open(...) as f:`** ≈ `using var writer = new StreamWriter(...)`.
  Always pass `newline=""` for CSV and an explicit `encoding`.

## Pillars in this lesson

| Pillar | Notice | Do |
|---|---|---|
| 🧭 Orchestration | `asyncio.gather` is fan-out: independent calls run concurrently, results come back in order. | Compare total wall-clock time, sequential vs `gather`. |
| 🧠 Context & memory | Pasting the supplier records into the prompt is the simplest form of context injection, the idea behind RAG (Module 2). | Remove the records from the task. How does quality change? |
| 🛡️ Guardrails | A cost estimate *before* a call enables budgets. | Add a `--budget-usd` option that skips a model whose estimated cost would exceed it (estimate input tokens with `client.messages.count_tokens`). |
| 🔐 Security & privacy | Privacy is part of the model choice: where data is processed and retained, not just which model is smartest. | Add a "Privacy notes" paragraph to your scorecard deliverable. |
| 📏 Evaluation | `keyword_quality` is your first eval: a fixed task, a fixed check, a number. Note its blind spots (a correct answer phrased differently scores 0). | Find one answer the metric scores wrongly, and note it for Module 6. |
| 🔭 Observability | The CSV is a run record you can compare across days and prompt versions. | Add a `timestamp` field to `ScorecardRow` with a default (`Field(default_factory=...)`) so existing tests still pass. |
| ⚡ Performance & cost | Cost per *correct* answer matters more than cost per call; latency varies run to run. | Run each model 3 times and report the median latency (`statistics.median`). |
| 🔁 Reliability | One failing model shouldn't lose the other results. | With `gather(..., return_exceptions=True)`, record a failed model as a row with quality 0 and the error message. |
